# Luka TV 🎬 — النسخة 2

## اللي اتضاف
- **حسابات للمشاهدين:** تسجيل بالإيميل، وقائمتي و«كمّل مشاهدة» بيتزامنوا على كل الأجهزة.
- **لوحة الإدارة مخفية:** بتظهر للأدمن بس، من «حسابي» بعد تسجيل الدخول.
- **أقسام حسب النوع** في الرئيسية + صفحة لكل نوع.
- **فلترة وترتيب:** النوع، السنة، التقييم، الأحدث/الأعلى تقييماً/الأكثر مشاهدة.
- **المشغّل:** جودات متعددة، سرعة 0.5x–2x، ترجمة، تخطي المقدمة، حلقة سابقة/تالية، صورة داخل صورة، عرض على الشاشة (Cast)، ملء شاشة بالعرض، إبقاء الشاشة شغّالة، وتحكم من إشعار الموبايل.
- **صفحة الفيلم:** ممثلون، تريلر، أفلام مشابهة، زرار «من البداية»، شريط تقدم على البوستر.
- **مظهر فاتح/غامق.**
- **وضع التلفزيون:** أزرار كبيرة وتحكم بالأسهم وEnter والرجوع في الريموت. بيشتغل تلقائياً على متصفحات Tizen وwebOS وAndroid TV، أو يتفعّل من «حسابي».
- **إشعارات داخل التطبيق** بالأفلام الجديدة والحلقات الجديدة (🔔 فوق).
- **إحصائيات الأدمن:** المشاهدات، الأكثر مشاهدة، عدد المستخدمين، ونسخة احتياطية JSON.
- **تجهيز لتطبيق الموبايل:** يفتح من غير نت (للمحتوى المحفوظ)، أيقونات PNG، اختصارات، دعم الحواف والنوتش، زرار تثبيت.

## ⚠️ خطوات التحديث (لازم بالترتيب)

### 1) حدّث قواعد Firebase (ضروري للحسابات والعدّاد)
1. Firebase ← **Firestore Database** ← تبويب **Rules**.
2. امسح كل القديم والصق محتوى `firestore.rules` الجديد (إيميل الأدمن فيه جاهز).
3. اضغط **Publish**.

### 2) ارفع الملفات على GitHub
ارفع (واستبدل) الملفات دي: `index.html` `style.css` `app.js` `sw.js` `manifest.json` `offline.html` `README.md`
(`firestore.rules` للنسخ بس، مش لازم يترفع). باقي الملفات سيبها زي ما هي.

### 3) افتح التطبيق
بعد دقيقتين افتح الرابط وحدّث الصفحة مرتين (السحب لتحت). لو لسه القديم ظاهر: Chrome ← ⋮ ← الإعدادات ← مسح بيانات الموقع.

## إضافة محتوى (من «حسابي» ← لوحة الإدارة)

| المطلوب | اكتب في الخانة |
|---|---|
| رابط واحد | `https://.../movie.mp4` |
| أكتر من جودة | `1080p@https://...mp4 ; 720p@https://...mp4` |
| ترجمة (فيلم) | `عربي@https://.../ar.vtt` (أو `.srt`) |
| حلقة | `1|3|1080p@https://a.mp4 ; 720p@https://b.mp4|https://subs/e3.vtt` (موسم\|حلقة\|فيديو\|ترجمة) |
| زرار تخطي المقدمة | حط «نهاية المقدمة» بالثواني (مثلاً 90) |

- ملفات الترجمة لازم تكون **UTF-8**، والأسهل ترفعها في نفس الـ repo على GitHub وتحط رابطها (من غير مشاكل CORS).
- الممثلين والتريلر بيتجابوا تلقائياً من TMDB، حتى للأفلام اللي ضفتها قبل كده.

## فلتر الاستخدام
- التطبيق للتجربة الشخصية. حط محتوى **مرخّص أو دومين عام** فقط (زي archive.org).
- كل مشاهدة بتتحسب لو المشاهد مسجّل دخول. الحدود المجانية في Firebase: 50 ألف قراءة و20 ألف كتابة يومياً. التطبيق بيحفظ العناوين 3 دقايق عشان يقلل القراءات.

## تحويله لتطبيق موبايل (APK)
1. **PWABuilder** (الأسهل): افتح pwabuilder.com ← الصق رابط الموقع ← Package For Stores ← Android. بعد التحديث ده هيطلع تقييم أعلى لأن الأيقونات والـ offline جاهزين.
2. **ملاحظة:** الـ APK من PWABuilder بيعرض شريط العنوان لأن الموقع على GitHub Pages. لو عايز تطبيق من غير الشريط ده، الخطوة الجاية بنجهزه بـ Capacitor ونبنيه مجاناً على GitHub من الموبايل.
3. **الإشعارات:** حالياً داخل التطبيق. إشعارات الموبايل وهو مقفول محتاجة سيرفر (FCM)، وبنضيفها مع نسخة Capacitor.
